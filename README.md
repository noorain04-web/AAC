# HearLink AAC — Adult Aphasia

A mobile-first Hindi/English AAC starter for adults with aphasia. Includes an urgent-message row, contextual grids, Basic single-tap speech, Conversation phrase building, editable text-to-speech, speech-rate and voice selection, locally saved phrases, and a basic offline app shell.

## GitHub Pages setup
1. Create or open your repository.
2. Upload `index.html`, `manifest.json`, `sw.js`, and `README.md` to the repository root.
3. In **Settings → Pages**, select deployment from the `main` branch and `/ (root)`.
4. Open the published HTTPS URL on your phone/tablet and test it with the intended user.

## Important
- Speech uses voices provided by the device/browser; the app does not bundle a voice. Install/enable a Hindi voice in device settings if needed. Voice quality and availability differ across devices.
- This web app cannot guarantee Bluetooth hearing-aid/headphone/external PA routing or native low-latency audio.
- The vocabulary is a starter and must be personalized with the user and speech-language therapist.
- The app does not call emergency services or contact caregivers. Keep another way to request urgent help.
- The attached project description mentioned a collection of 1,055 IDC symbols, but those image files were not available as individual assets here. This starter uses emoji placeholders. Add only images you have permission to use and redistribute.
- Saved messages remain in local browser storage on this device. Clearing browser/site data can erase them.
